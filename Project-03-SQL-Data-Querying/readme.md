# Project 3: SQL & Data Querying

This project focuses on applying SQL skills to real-world datasets using database setup, data querying, advanced SQL concepts, business problem solving, and query optimisation.

## Files Included

- **Chinook_MySql.sql** – SQL queries and analysis performed on the Chinook Music Store database.
- **Sales_Data_SQL_Script.sql** – SQL scripts for analysing the Sales dataset, including core queries, aggregations, subqueries, window functions, business analysis, and indexing.
- **Week_3_SQL_Report.pdf** – Documentation of the SQL queries, analysis, key findings, and insights from both datasets.

## Tools Used

- MySQL / SQL
- SQL Server
- SQL Client
- GitHub

## Key Concepts Covered

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- Joins
- Subqueries
- Window Functions
- RANK() and ROW_NUMBER()
- PARTITION BY
- Business Problem Solving
- Query Optimisation and Indexing
